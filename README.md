# المساعد الذكي — بوت تيليجرام

بوت واحد يجمع: سؤال وجواب، تلخيص، ترجمة، كتابة محتوى، تفريغ صوت إلى نص، تحميل فيديوهات، تحويل صيغ، ضغط صور، وأدوات PDF.

## الملفات

| الملف | وظيفته |
|---|---|
| `bot.py` | نقطة التشغيل: الأوامر، استقبال الملفات، الأزرار |
| `ai.py` | سؤال/تلخيص/ترجمة/كتابة عبر واجهة النموذج اللغوي |
| `media.py` | yt-dlp للتحميل، ffmpeg للتحويل، Whisper للتفريغ |
| `filetools.py` | ضغط الصور، PDF، تحويل مستندات Office |
| `config.py` | المفاتيح والحدود والعدّاد اليومي |
| `Dockerfile` | بيئة التشغيل مع ffmpeg و LibreOffice |

## التشغيل من الجوال (بدون كمبيوتر)

### ١) إنشاء البوت
افتح تيليجرام → ابحث عن **@BotFather** → `/newbot` → اختر اسمًا ومعرّفًا ينتهي بـ `bot`.
انسخ التوكن الذي يعطيك إياه.

اختياري لعرض الأوامر داخل تيليجرام: أرسل `/setcommands` ثم الصق:

```
start - البداية
help - الأوامر
ask - سؤال وجواب
sum - تلخيص نص
tr - ترجمة نص
write - كتابة محتوى
dl - تحميل فيديو برابط
mp3 - تحميل صوت برابط
merge - دمج ملفات PDF أو صور
done - إنهاء الدمج
limits - الرصيد اليومي
reset - مسح السياق
```

### ٢) جلب المفاتيح
- مفتاح الذكاء الاصطناعي من لوحة Anthropic (`console.anthropic.com`).
- مفتاح التفريغ الصوتي من Groq (`console.groq.com`) — سريع وله طبقة مجانية، ومتوافق مع واجهة OpenAI. لو فضّلت OpenAI غيّر `WHISPER_BASE_URL` إلى `https://api.openai.com/v1`.

### ٣) رفع المشروع على GitHub
من متصفح الجوال: `github.com` → New repository → اجعله **Private** → داخل المستودع: `Add file` → `Upload files` → ارفع كل ملفات المجلد.

### ٤) النشر على Railway
`railway.com` → سجّل بحساب GitHub → New Project → Deploy from GitHub repo → اختر المستودع.
سيكتشف `Dockerfile` تلقائيًا. بعدها من تبويب **Variables** أضف المتغيّرات الموجودة في `.env.example`.

بعد اكتمال النشر، افتح بوتك في تيليجرام وأرسل `/start`.

> البوت يعمل بنظام polling، فلا يحتاج دومين ولا إعداد webhook. لكنه يحتاج استضافة تعمل ٢٤ ساعة بدون نوم — توقّع تكلفة تبدأ من حوالي ٥ دولار شهريًا بعد انتهاء الرصيد التجريبي. البدائل: Fly.io أو أي VPS.

## حدود وأمور مهمة

**حدود تيليجرام (لا يمكن تجاوزها ببوت عادي)**
- استقبال ملف: ٢٠ ميجا كحد أقصى.
- إرسال ملف: ٥٠ ميجا كحد أقصى. البوت يضغط الفيديو تلقائيًا عند التجاوز، وإن بقي كبيرًا ينبّهك.
- لرفع الحد إلى ٢ جيجا تحتاج تشغيل *Telegram Bot API Server* محلي — خطوة متقدمة لاحقة.

**تحميل الفيديو**
- yt-dlp يعمل مع معظم المنصات، لكن يوتيوب يحجب عناوين سيرفرات الاستضافة كثيرًا ويطلب تحقّقًا. الحل: ملف كوكيز عبر `COOKIES_FILE`، أو بروكسي سكني.
- لكل منصة شروط استخدام خاصة بالتحميل. يفضّل حصر الاستخدام في المحتوى الذي تملكه أو المصرّح بتحميله.
- لإطفاء الميزة كليًا: `ALLOW_VIDEO_DOWNLOAD=0`.

**التكلفة والاستهلاك**
- استدعاءات النموذج والتفريغ بالاستخدام. `DAILY_LIMIT` يحدّ عمليات كل مستخدم يوميًا (٣٠ افتراضيًا).
- لجعل البوت خاصًا بك: ضع معرّفك الرقمي في `ALLOWED_USERS`. (تعرف رقمك من بوت مثل @userinfobot.)

**الحالة في الذاكرة**
- سياق المحادثة والعدّاد اليومي محفوظان في ذاكرة التشغيل، ويُصفّران عند إعادة النشر. لو احتجت ثباتًا لاحقًا، أضف SQLite أو Redis.

**الملفات المؤقتة**
- كل عملية تشتغل في مجلد مؤقت يُحذف تلقائيًا بعد الانتهاء، فلا يتراكم شيء على القرص.

## إضافات مقترحة لاحقًا
- OCR للملفات الممسوحة (tesseract + الصور الناتجة من PDF).

- ربط التفريغ والترجمة بأداة القص لتوليد الشورتس مباشرة من البوت.
